資料備份

localStorage 只存在目前瀏覽器。不同瀏覽器與 iPhone 主畫面圖示可能使用獨立資料空間，不會自動同步。請定期匯出並保存 JSON。

合併會依紀錄 ID 去重，保留兩邊新增的紀錄；遇到同 ID 但內容不同時不會直接覆蓋，會提示衝突。匯入前會自動下載目前備份。

V1 規則

工作收入＝診所／公司轉給個人的資金。貸款專戶轉入直接記「個人支出／貸款」，不再記銀行後續扣款。月結只填病人、健保、藥費。退款於確認退款時新增一筆「退款」，不列收入，會沖減該月與專案支出；舊信用卡帳單繳款不重複列消費。管理帳不等於報稅帳。
